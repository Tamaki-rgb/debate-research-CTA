# Does Debate Training Develop Critical Thinking?

**Independent Research Project**  
Shymkent, Kazakhstan | 2026

A data-driven study investigating the impact of debate participation on critical thinking skills among secondary school students.

### Project Overview

I conducted a survey with **over 100 students** (38 with debate experience vs 62 without) to measure how debate training affects critical thinking abilities.

This project perfectly combines my debate experience with data analysis — the exact direction I want to pursue in Data Science.

### Key Findings

- Debate participants demonstrated **+30% higher overall scores**
- Largest differences in:
  - **Source Evaluation**: 65.8% vs 33.1%
  - **Openness to Change**: 63.2% vs 33.9%
  - **Structured Thinking**: 72.8% vs 43.0%

### Methodology

- Sample: 100+ anonymous respondents from Shymkent schools
- 16 scenario-based questions inspired by Watson-Glaser Critical Thinking Appraisal
- Analysis performed in Python (pandas + matplotlib)
- Comparison between debate and non-debate groups
